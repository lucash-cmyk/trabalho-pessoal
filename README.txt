# Bianka & Caio ❤️

Site romântico com:
- Frase "Eu te amo pra sempre ❤️"
- Data de início: 01/05/2024
- Contador ao vivo de anos, meses, semanas, dias, horas, minutos e segundos
- Galeria com as 12 fotos enviadas
- Música do YouTube
- Layout responsivo para celular e computador

## Como abrir

1. Extraia o ZIP.
2. Abra a pasta.
3. Dê dois cliques em `index.html`.
4. Para tocar a música, clique em "Tocar".

## Como trocar a música

Abra `script.js` e altere:

const youtubeId = "Af7ieNv0wXY";

O ID é a parte depois de `v=` no link do YouTube.

Exemplo:
https://www.youtube.com/watch?v=ABC12345678
ID:
ABC12345678

## Como trocar as fotos

As fotos ficam na pasta `imagens`.

Você pode substituir os arquivos mantendo os nomes:
foto-1.jpeg
foto-2.jpeg
...
foto-12.jpeg
